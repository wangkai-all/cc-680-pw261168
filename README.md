# 门店体验评分补全实验室

用带正则的低秩模型，为「门店 × 服务评分」矩阵补全**有依据**的缺失格；没有依据的格子宁可保持空白，也绝不画成 0 分。前后端均为本地运行，无任何第三方运行时依赖。

```bash
npm start        # http://127.0.0.1:4173
npm test         # node:test，覆盖留出 / 探针 / 诊断 / HTTP 接口
npm run check    # 语法检查
npm run export:data   # 把当前种子生成的数据冻结到 data/
```

需要 Node.js ≥ 20。运行时零第三方依赖。

`scripts/` 下的截图 / 交互脚本仅用于开发期验证，依赖 `playwright-core`；它不是项目依赖，运行时通过 `PLAYWRIGHT_CORE=/path/to/playwright-core/index.js` 指定即可。

## 数据

数据由 `server/data.js` 在本地按固定种子（`20261122`）合成，每次启动完全一致：

- **38 家门店 × 18 个评分项 = 684 格**，只有 **264 格**有真实评分（38.6%）。
- 缺失是**非均匀**的：门店响应倾向、评分项投放偏好、设施条件（停车 / 试衣间 / 母婴）以及真实得分本身共同决定是否被观测。
- 每条评分属于**唯一一个调查批次**；共 12 个批次，批次之间带轻微整体水平偏移。
- 观测关系分成**两个互不相连的问卷块**（28 家主问卷门店 × 12 项；8 家奥莱门店 × 5 项）。
- **2 家门店**（新城筹备店、老码头店）和 **1 个评分项**（屋顶露台体验）从未有观测。
- 默认留出批次由 `DEFAULT_HOLDOUT_BATCHES` 指定：`W05`（夏季回访）与 `O02`（奥莱夏季问卷）。

`data/` 下是 `npm run export:data` 生成的快照，服务端始终按种子现算，不读取快照。

## 模型

```
r̂(门店, 项目) = μ + b_门店 + c_项目 + p_门店 · q_项目
```

交替最小二乘（ALS），对偏置与因子做 ridge 正则；只读取**原始训练评分**。留出、遮蔽、缺失格永远不会以补全值回流到拟合中（`analysis.js` 中 `alsUsesRawTrainingRatingsOnly: true`，测试 `masked/held-out ratings do not influence the fit` 会改动这些格子的真值并断言估计完全不变）。

每个训练连通块独立拟合，多个随机初始化取逐格均值作为补全值，初始化之间的标准差作为稳定度。

## 页面语义

| 关注点 | 行为 |
| --- | --- |
| 缺失 | 未知格保持空白 / 斜纹；**不显示误差，不显示 0** |
| 从未观测 | 行或列从无评分：整行 / 整列标注「从未观测 / 未投放」，不给估计 |
| 跨块 | 行与列分属两个观测块：格子标「跨块无依据」，不给估计，并给出区块警示 |
| 整批留出 | 按整个调查批次划分，同一份问卷不会一半训练、一半验证；每个留出批次单独给样本量与误差 |
| 留出误差 | 单独展示；没有可评估留出观测时显示「—」并给出 critical 警告，训练误差不会冒充留出误差 |
| 区块遮蔽 | 选一整块已知评分暂时遮住，用它的真值检验整块重建能力，再一键恢复原数据；遮蔽只影响本次训练的排除条件 |
| 复杂度 | 秩 / λ / 初始化次数可调；扫描每一档都完整重拟合，留出误差缺失的档位断线而非归零 |
| 收敛 vs 塌缩 | **两件不同的事**：「尚未收敛」指 ALS 在迭代上限内没有稳定停点；「均值塌缩」指 λ 过强导致补全值压向总均值，即使已经收敛也会出现 |
| 格子详情 | 点任一格可看其行 / 列的真实观测、训练范围（仅原始训练评分）、多次初始化的补全值与标准差 |

## 关键阈值

- 收敛：训练 RMSE 相对变化 < `1e-5` 连续 3 轮，或达到 90 轮上限（`server/analysis.js`）。
- 均值塌缩：块内训练解释方差 ≤ 20%，或补全值离散度 / 训练离散度 < 0.4，或近均值比例 > 55% 且离散度比 < 0.8。
- 稳定：多次初始化的逐格标准差 ≤ 0.02；1 次初始化时显示「需多次初始化」，不伪造 0。

## 结构

```
server/
  data.js       本地非均匀缺失数据生成（固定种子）
  model.js      ALS + ridge，单连通块拟合
  analysis.js   留出 / 遮蔽 / 连通块 / 误差 / 诊断的完整管线
  presets.js    预置遮蔽区块
  sweep.js      秩 / λ 扫描（每档完整重拟合）
  index.js      node:http 服务与静态资源
public/
  index.html    页面结构
  app.js        状态、渲染、交互
  charts.js     无依赖 SVG 图表
  styles.css    明暗主题与矩阵样式
test/           node:test 断言上述不变量
scripts/        数据集导出与开发期截图脚本
```
